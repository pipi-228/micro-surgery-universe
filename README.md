# Micro-Surgery Universe — «Квантовый хирург» на WPF

Аркада с физикой частиц на C# и WPF: на игровом поле летает рой цветных частиц и их античастиц, а игрок управляет процессом их уничтожения и гравитационным взаимодействием между ними, зарабатывая очки и стараясь не потерять все жизни.

## Игровой процесс

- На поле одновременно движется рой частиц. У каждой частицы есть цвет и тип — обычная частица или античастица.
- Частицы одного цвета притягиваются друг к другу; частицы разных типов (частица и античастица) одного цвета при столкновении **аннигилируют** — обе исчезают, а игрок теряет жизнь (если не активен щит).
- **ЛКМ** по частице — убрать её с поля вручную, +10 очков.
- **ПКМ** на игровом поле — создать временную гравитационную яму, которая притягивает или отталкивает окрестные частицы.
- Ползунок скорости в верхней панели регулирует общий темп игры: гравитацию, максимальную скорость частиц и частоту их появления.
- Периодически на поле появляются золотые бонусные частицы со случайным эффектом.
- Игра заканчивается, когда у игрока заканчиваются жизни (3 в начале, можно восполнить бонусом).

## Бонусы

| Бонус | Иконка | Эффект |
|---|---|---|
| Замедление | 🐢 | Снижает общую скорость игры на 60% на время действия бонуса |
| Двойные очки | ⭐ | Умножает получаемые очки на 2 |
| Щит | 🛡️ | Защищает от потери жизни при следующей аннигиляции |
| Мега-яма | 🌀 | Мгновенно создаёт мощную гравитационную яму в центре поля |
| Восстановление жизни | 💚 | Добавляет одну жизнь (максимум 5) |

Активный бонус и оставшееся время его действия отображаются в нижней панели интерфейса.

## Физика

- На каждую пару частиц действует гравитационная сила, обратно пропорциональная квадрату расстояния между ними (по аналогии с законом всемирного тяготения); знак силы (притяжение/отталкивание) зависит от того, совпадают ли цвет и тип частиц.
- Частицы также попадают под действие временных гравитационных ям (создаваемых ПКМ или бонусом «Мега-яма»), которые всегда притягивают.
- Столкновение с границами игрового поля обрабатывается упругим отскоком с частичной потерей скорости.
- Скорость частиц ограничена максимальным значением, которое масштабируется ползунком скорости.
- Расчёт физики выполняется на каждом тике `DispatcherTimer` (~60 раз в секунду).

## Интерфейс

- Верхняя панель: количество очков, число оставшихся жизней, счётчик частиц на поле, ползунок скорости игры, кнопка «Новая игра».
- Индикатор активного бонуса и таймер его действия.
- Нижняя панель с подсказками по управлению (ЛКМ/ПКМ) и правилами аннигиляции.
- Визуальные эффекты: анимированная вспышка при аннигиляции, эффект щита, разлетающиеся искры при сборе бонуса, пульсирующая гравитационная яма с исчезающим ореолом при истечении времени действия.

## Требования

- Windows
- .NET Framework и Visual Studio (workload «.NET desktop development»)

## Запуск

1. Откройте `WpfApp1.sln` в Visual Studio.
2. Соберите и запустите проект.
3. Кликайте ЛКМ по частицам, чтобы убирать их с поля и зарабатывать очки; используйте ПКМ, чтобы создавать гравитационные ямы и управлять роем.
4. Следите за жизнями: не допускайте лишних аннигиляций одноцветных частица/античастица без активного щита.
5. Собирайте золотые бонусные частицы для получения временных преимуществ.

## Технологии

- C#, WPF: `Canvas`, `Shapes` (`Rectangle`, `Ellipse`), `Media` (градиенты, `DropShadowEffect`), `Animation` (`DoubleAnimation`, `ScaleTransform`)
- `System.Windows.Threading.DispatcherTimer` — игровой цикл, спавн частиц, таймер бонусов

## Примечание

Изначальное техническое задание для этого проекта было написано под другую игру («Magnetic Cascade» — аркада про магнитный полюс и падающие сферы), но в реализации оно было адаптировано в самостоятельную игру с иной механикой — на частицах, античастицах и аннигиляции. Описание в этом README соответствует фактическому коду репозитория.
